Shows all Firestore collections, their fields, and relationships within the MotionSync Coach system

📊 Firestore Database Schema

USER

Central entity stored at users/{uid} in Firestore. Contains profile info (email, name, age, gender, height, weight, fitness goal) with timestamps.

WORKOUT_SESSION

Sub-collection users/{uid}/workout_sessions. Captures the exercise name, reps, sets, rest time, and date. References Exercise by name.

FORM_SESSION_RECORD

Sub-collection users/{uid}/form_session_records. Stores AI form analysis — total frames analyzed, good form frames, and mistake counts.

BMI_RECORD

Sub-collection users/{uid}/bmi_history. Tracks BMI over time with value, weight, height, and date.

NUTRITION_PLAN

Sub-collection users/{uid}/nutrition_plans. Stores meal plans with name, list of meals, and date.

EXERCISE (In-App)

Defined in code (not Firestore). Exercise metadata: instructions, images, GIFs, ML model paths, keypoint config, targeted muscles, correction videos.

Architecture Overview

How MotionSync Coach's layers interact — from UI screens down to AI and Firestore

🧩 System Architecture Flow

UI Layer

17 Flutter screens handling auth flows, home dashboard, exercise selection, real-time camera workout, profile management, BMI calculator, nutrition, progress reports, and settings.

Service Layer

FirebaseAuthService — login/signup/Google. FirestoreService — all Firestore CRUD. SettingsService — preferences. VoiceControlService + AppVoiceControl — hands-free voice commands.

AI Pipeline

PoseDetector — ML Kit 33 landmarks. FormClassifier — TFLite form correctness. RepCounter — keypoint-based rep tracking. CoachTTS — audio feedback. RenderLandmarks — skeleton overlay.

Data Layer

Firebase Auth for authentication. Cloud Firestore for all user data. SharedPreferences for local settings. TFLite models for on-device AI.
