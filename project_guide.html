🚀 Project Overview

MotionSync.AI is a sophisticated mobile application designed to democratize fitness coaching. By leveraging Computer Vision, the app provides real-time feedback to users working out from home, ensuring exercise safety and maximizing efficiency.

We have transitioned from standard pose estimation to a robust Object Detection & Pose Classification pipeline using Ultralytics YOLO. This allows for higher accuracy in detecting complex body mechanics in varied lighting conditions.

🛠️ Data & Training Pipeline

The core intelligence of the app is built upon a rigorous data pipeline. We handle three specific workout types: Push Ups, Pull Ups, and Squats.

1. Data Collection & Preparation

We have installed and curated specialized video datasets for each exercise. Raw video footage undergoes a strict cleaning process:

  • Frame Extraction: Converting video to image frames.
  • Annotation: Labeling bounding boxes and keypoints.
  • Augmentation: Flipping, rotation, and brightness adjustments to ensure model robustness.

2. Model Training (Python/Ultralytics)

Using the Ultralytics YOLO framework in Python, we train custom models for each exercise.

Key App Features
